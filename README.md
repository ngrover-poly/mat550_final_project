# US Labor Market: A Systemic Time Series Study
**Operational Context:** Analysis of Total Nonfarm Job Openings, Hires, and Quits Rates to support economic forecasting and labor policy decisions.

## How to Reproduce
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the notebook: `MAT550_final_Grover.ipynb`
4. Launch the dashboard: `streamlit run app.py`

## Project Impact
This study identifies the lead-lag relationship between labor demand and recruitment, providing a tool for decision-makers to anticipate market cooling or tightening up to 12 months in advance.
